# Third-party assets

The UI includes the minified CSS from Bootstrap 5.3.3, by The Bootstrap Authors,
under the MIT license. Its copyright header is preserved; the complete license
is stored alongside the CSS in `src/YtDownloader.Web/wwwroot/lib/bootstrap/LICENSE`.

NuGet dependencies retain their own licenses and attribution. Their package
references and versions are listed in project files and `Directory.Packages.props`.

FFmpeg is a separately installed runtime dependency. Its binaries and any
downloaded media are excluded from this source repository.
